# Robô de Ordenação

O Robô de Ordenação é um projeto desenvolvido para uma atividade prática da disciplina de **Estrutura de Dados II**, da professora **Karla**. O projeto tem como objetivo analisar e comparar o funcionamento de diferentes algoritmos de ordenação.

O programa utiliza os algoritmos **Bubble Sort, Insertion Sort, Selection Sort e Quick Sort**. Ele gera um vetor com números aleatórios de acordo com a quantidade de elementos informada pelo usuário e utiliza cópias desse mesmo vetor para executar cada algoritmo em condições iguais.

Durante a execução, o programa conta a quantidade de **comparações e movimentações** realizadas por cada algoritmo e apresenta os resultados na tela. Dessa forma, é possível observar como cada algoritmo se comporta conforme aumenta a quantidade de elementos e comparar os resultados obtidos entre eles.

O projeto foi desenvolvido em **Python** como parte da atividade prática de **Estrutura de Dados II**.
