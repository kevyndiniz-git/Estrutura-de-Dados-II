# Algoritmos de Ordenação

Neste arquivo estão as classes BubbleSort, QuickSort, SelectionSort e InsertionSort, que são classes filhas de AlgoritmoOrdenacao. As quatro utilizam a estrutura definida pela classe pai e possuem seus próprios métodos para realizar a ordenação dos elementos.

No BubbleSort, os elementos são comparados entre si e trocados quando estão na ordem incorreta. No QuickSort, é escolhido um elemento como pivô para dividir o vetor em partes menores, que são ordenadas de forma recursiva. No SelectionSort, é encontrado o menor elemento da parte não ordenada e ele é colocado na posição correta. No InsertionSort, os elementos são inseridos na posição correta dentro da parte já ordenada.

Durante a execução dos quatro algoritmos, são contabilizadas as comparações e movimentações realizadas.

O programa permite realizar experimentos com diferentes quantidades de elementos e comparar os resultados dos algoritmos utilizando vetores aleatórios, ordenados e em ordem inversa.
